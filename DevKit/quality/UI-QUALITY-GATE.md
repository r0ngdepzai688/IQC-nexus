# UI Quality Gate

## Product character

- [ ] Industrial neutral surfaces, one controlled accent, thin borders, modest
  radii, restrained shadow, and consistent spacing/type tokens are used.
- [ ] No decorative gradients, blobs, glass-heavy surfaces, sparkle icons,
  fabricated confidence, fake AI claims, or unlabeled fixture data remain.
- [ ] Operational density is usable on desktop and tablet.

## Workflow

- [ ] Login has labels, keyboard flow, visible focus, password visibility,
  pending state, and sanitized invalid/disabled states.
- [ ] Navigation has a visible active state and keyboard/mobile collapse.
- [ ] Import screens cover loading, empty, error, forbidden, and success states.
- [ ] NASCA is clearly Client Agent-only; the browser never supplies local paths.
- [ ] Mapping shows coordinates, required fields, transforms, unmapped and
  duplicate warnings, reset, and explicit confirmation.
- [ ] Preview has counts, sticky headers, filters, coordinates, readable
  messages, pagination/virtualization, and explicit commit confirmation.
- [ ] Blocking errors disable commit.

## Accessibility

- [ ] Semantic elements and associated labels are present.
- [ ] Focus is visible and dialogs manage focus/Escape correctly.
- [ ] Status is not conveyed by color alone and contrast is sufficient.
- [ ] Reduced motion is respected.
- [ ] Personnel displays use the interactive `UserBadge` component.
